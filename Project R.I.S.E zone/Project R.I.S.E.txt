Data/

Esta pasta é uma das alterações que eu faria no novo site.

Data/
├── heroes.js
├── perks.js
├── enemies.js
├── bosses.js
├── floors.js
├── items.js
└── news.js

Em vez de escreveres todas as informações diretamente no HTML, podes guardar os dados aqui.

Por exemplo:

const heroes = [
    {
        id: "barbarian",
        name: "Barbarian",
        rarity: "...",
        health: "...",
        damage: "..."
    }
];

Depois o JavaScript constrói os cards e páginas.

Isto vai poupar-te MUITO trabalho.
